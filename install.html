학교 관리자가 처음 한 번만 합니다. 5분쯤 걸립니다.

템플릿 사본 만들기

학교 관리자 구글 계정으로 로그인한 상태에서 아래 버튼을 누르고 사본 만들기를 누릅니다. 사본은 내 드라이브에 저장되고, 이 사본이 우리 학교 전용 Pindex가 됩니다.

사본 만들기 화면 열기

권한 승인은 설치 중 한 번만 합니다(4단계). 사본의 Pindex 메뉴는 누르지 않아도 됩니다.
브라우저에 구글 계정이 여러 개 로그인되어 있으면 나중에 화면이 안 열릴 수 있습니다. 관리자 계정 하나만 로그인된 크롬 프로필이나 시크릿 창에서 진행하세요.

확장 프로그램 › Apps Script

만든 사본(구글 시트) 위쪽 메뉴에서 확장 프로그램을 누르고 Apps Script를 누릅니다. 새 탭에 편집기가 열립니다. 코드가 보여도 고칠 필요는 없습니다.

오른쪽 위 파란 [배포] → [새 배포]

편집기 오른쪽 위의 파란 배포 버튼을 누르고, 펼쳐진 메뉴에서 새 배포를 누릅니다.

배포 관리가 아니라 새 배포입니다. 처음 한 번만 새 배포를 만듭니다.

톱니바퀴 → [웹 앱]

'새 배포' 창 왼쪽 위 유형 선택 옆의 톱니바퀴를 누르고, 목록에서 웹 앱을 고릅니다.

아무것도 바꾸지 말고 [배포]

오른쪽 설정은 이미 맞게 채워져 있습니다(실행: 나, 액세스: 모든 사용자). 그대로 오른쪽 아래 배포를 누릅니다.

혹시 다르게 되어 있으면 위 그림처럼 바꿔 주세요. 'Google 계정이 있는 모든 사용자'나 '나만'이면 선생님들 휴대폰에서 QR이 열리지 않습니다.

권한 승인 (설치 중 한 번뿐)

배포를 누르면 권한 승인을 묻습니다. 아래 세 화면을 차례로 지나면 됩니다.

① [액세스 승인] → 내 계정 고르기

'데이터 액세스 권한을 부여해야 합니다'라는 안내가 나오면 액세스 승인을 누르고, 새 창에서 이 시트를 가진 내 계정을 고릅니다.

② "확인하지 않은 앱" 경고가 나와도 괜찮습니다

왼쪽 아래 작은 글씨 고급을 누르고, 맨 아래 …(으)로 이동(안전하지 않음)을 누릅니다.

왜 이런 경고가 나오나요? 이 앱은 선생님이 방금 사본으로 만든, 구글의 심사를 받지 않은 앱이라서 누구에게나 이 경고가 나옵니다. Pindex는 선생님 계정의 권한으로만 돌아가고, 대여 기록은 이 시트에만 저장되며 다른 서버에 따로 모아 두지 않습니다.

'안전한 페이지로 돌아가기'를 누르면 처음부터 다시 해야 합니다.

③ 권한 확인 → [허용]

Pindex가 쓸 권한 목록이 나옵니다. 아래로 내려 허용(또는 계속)을 누릅니다.

권한마다 체크 상자가 보이면 모두 선택을 체크해 주세요. 하나라도 빠지면 일부 기능이 동작하지 않습니다.

웹 앱 URL을 열면 끝

배포가 끝나면 나오는 창에서 웹 앱 URL 아래 복사를 누르고, 새 탭 주소창에 붙여 넣어 엽니다. 처음 한 번은 시트를 준비하느라 몇 초 걸리고, 현황판이 보이면 끝입니다.

주소를 따로 적어 둘 필요는 없습니다. 한 번 열면 시트 맨 앞 시작 탭에 ▶ 관리자 화면 열기 링크가 생기고, 메뉴 Pindex › 관리자 화면 열기로도 열 수 있습니다.
다음 순서: 설정(학교명·학급) → 물품 등록 → QR 인쇄
나중에 다시 배포할 때는 배포 관리에서 기존 배포를 수정하세요. 새 배포를 또 만들면 주소가 바뀌어 붙여 둔 QR이 열리지 않습니다.

버튼 이름과 모양은 구글 화면 변경에 따라 조금 다를 수 있습니다.
